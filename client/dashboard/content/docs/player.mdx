# Player

MotionMesh transcodes every video into HLS renditions. Play them back with any HLS-capable player — no extra SDK required.

## Get the playback URL

`GET /v1/videos/{id}/playback` returns the signed HLS playlist, subtitle, and timeline sprite URLs for a ready video:

```json
{
  "playlistUrl": "https://api.motionmesh.co.in/v1/videos/vid_abc/hls/master.m3u8",
  "subtitleUrl": "https://api.motionmesh.co.in/v1/videos/vid_abc/captions/en.vtt",
  "timelineSpritesUrl": "https://api.motionmesh.co.in/v1/videos/vid_abc/sprites.jpg"
}
```

## hls.js (all browsers)

```tsx
import Hls from "hls.js";

const video = document.createElement("video");
if (Hls.isSupported()) {
  const hls = new Hls();
  hls.loadSource("https://api.motionmesh.co.in/v1/videos/vid_abc/hls/master.m3u8");
  hls.attachMedia(video);
}
```

## Native HTML5 video

Safari plays HLS natively — no JavaScript needed:

```html
<video controls>
  <source src="https://api.motionmesh.co.in/v1/videos/vid_abc/hls/master.m3u8" type="application/x-mpegURL" />
</video>
```

## Captions

Attach the generated WebVTT file as a `<track>` element:

```html
<video controls>
  <source src="https://api.motionmesh.co.in/v1/videos/vid_abc/hls/master.m3u8" type="application/x-mpegURL" />
  <track
    kind="subtitles"
    src="https://api.motionmesh.co.in/v1/videos/vid_abc/captions/en.vtt"
    srclang="en"
    label="English"
    default
  />
</video>
```
